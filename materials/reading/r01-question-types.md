# R01 — The 8 Question Types

**Section:** Reading Comprehension · **Time budget:** 50 questions in 55 minutes = **66 s/question**

---

## The attack order — never answer in printed order

Answer types in the order below. It front-loads the cheap points and leaves the expensive
ones for when you already understand the passage.

| Order | Type | Cost | Where the answer lives |
|---:|---|---|---|
| 1 | Vocabulary in context | cheap | One line — go straight to it |
| 2 | Detail (stated fact) | cheap | Scan for the keyword |
| 3 | NOT / EXCEPT | medium | Scan for 3 true, keep the odd one |
| 4 | Pronoun reference | cheap | Look **before** the pronoun |
| 5 | Inference | expensive | Must be true if the passage is true |
| 6 | Main idea | expensive | First and last sentences of each paragraph |
| 7 | Tone / purpose / organisation | expensive | Adjectives and structure words |
| 8 | Insert-a-sentence | expensive | Coherence: *this/that/however/for example* |

---

## 1. Vocabulary in context (~5 questions per test)

> **Cover the answer choices.** Read the sentence, supply your own word, then match.

The four options are usually all possible meanings of the word — only one fits *this* context.
```
The proposal was ultimately rejected.
(A) finally  (B) surprisingly  (C) narrowly  (D) temporarily   → A
```

---

## 2. Detail — stated fact (~10 questions)

Find a keyword (a name, a date, an unusual noun), scan for it, read one sentence before and
one after. The answer is a **paraphrase**, not a copy of the sentence — match meaning, not wording.

---

## 3. NOT / EXCEPT (~5 questions) ⭐ high yield

The wording is negative — *"All of the following are true EXCEPT"*, *"NOT mentioned"*.
Three options are stated in the passage; one is not.

**Method:** locate the list in the passage (usually one paragraph), then tick off A, B, C, D
against it. The one with no support is the answer.
⚠️ Write "NOT" in large letters on your paper the moment you see it. Most lost points on this
type come from misreading the question, not from the passage.

---

## 4. Pronoun reference (~3 questions)

`it / they / these / this / which / such / one / those`

**Method:** read **backwards** from the pronoun. The antecedent is usually the most recent
matching noun. Test your answer by substitution — the sentence must still make sense.
⚠️ `which` at the start of a clause often refers to the **entire previous idea**, not one noun.

---

## 5. Inference (~8 questions)

> An inference is something that **must be true if the passage is true**. Not something that
> *could* be true.

**Test each option:** can I point to the sentence that proves it? If you need outside knowledge
or extra imagination, it's wrong.

| Signal word in the question | What it means |
|---|---|
| *infer / imply / suggest* | Find a statement the passage supports indirectly |
| *probably / likely* | Choose the most supported, mildest option |
| *most likely agrees* | Find the author's opinion, then match |

⚠️ **Never choose an option that contradicts the passage.** ⚠️ **Never choose an extreme option**
(*always, never, all, none, impossible*) unless the passage says so.

---

## 6. Main idea (~5 questions)

**Method:** read the first two sentences of the passage, and the first sentence of every
paragraph. The main idea is the claim those sentences keep returning to.

- Too broad → mentions things outside the passage.
- Too narrow → describes only one paragraph.
- Right → covers the whole passage without going beyond it.

Variants: *best title* · *the passage primarily discusses* · *the author's main point*.

---

## 7. Tone / purpose / organisation (~4 questions)

| Tone words (positive) | Tone words (negative) | Tone words (neutral) |
|---|---|---|
| appreciative, admiring, supportive, enthusiastic, optimistic | critical, skeptical, dismissive, concerned, alarmed, ironic | objective, analytical, neutral, descriptive, informative |

**Purpose patterns:** *to describe* · *to argue* · *to explain why* · *to compare* ·
*to trace the development of* · *to refute* · *to illustrate*

⚠️ Tone questions are decided by **adjectives and verbs**: *unfortunately, remarkably,
questionable, a serious flaw, a welcome development*.

---

## 8. Insert-a-sentence (~2 questions)

Four squares ■ mark possible positions. Put the sentence back by looking for:

- **Pronouns** — *it / they / these* must refer to something already mentioned.
- **Demonstratives** — *this theory / such methods* must follow the thing they describe.
- **Logic connectors** — *however / therefore / for example / in addition* must follow the
  sentence they react to.
- **General → specific** — a general claim comes before its example.

---

## Timing plan for 55 minutes

| Elapsed | You should be |
|---|---|
| 0–4 min | Read passage 1 fully (don't skim — skimming costs more than it saves) |
| 4–14 min | Answer passage 1's ~10 questions |
| 14–45 min | Passages 2–4 at ~8 min each |
| 45–53 min | Passage 5 |
| 53–55 min | Bubble check — every question answered |

**Hard rule:** if a question takes more than 90 seconds, guess, mark it, move on. Come back
only if there is time left. An unanswered question is worth 0; a guess is worth 25%.
