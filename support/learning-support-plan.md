## 2. Why Structure is the right place to start

Not because it's "easy" — because of how it behaves:

| Property | Consequence for planning |
|---|---|
| Bounded content (~15 recurring rules) | Can actually be finished, unlike vocabulary |
| Shortest section (25 min for 40 Q) | Highest points-per-minute on the test |
| Rules are *declarative* | Can be written on a card and checked, which suits a log-based workflow |
| Errors are *classifiable* | Every miss maps to a named module → the error log becomes actionable |

So: **front-load it (Weeks 0–1), then maintain it weekly.** Grammar decays fastest of the three
sections, which is why Weeks 2–5 each carry a maintenance drill.

## 3. Four support dimensions

### A. Study-session strategies

| Need it addresses | What to do | Frequency | How to tell it's working |
|---|---|---|---|
| Long unstructured sessions lose focus | **Fixed 6-block session shape** (warm-up 5 / instruction 25 / guided 20 / timed 25 / error review 20 / commit 5). A timer, visible, for each block. | Every session | You finish inside budget without staring at the clock |
| Passive reading feels productive but isn't | **Every module ends in a timed drill.** No module counts as done until it has a number. | Every session | Daily log has a score in it, every day |
| Working memory overload on error-identification | **The slot test:** before reading options, name what part of speech the blank needs. | Weeks 0–1, then as needed | Time-to-answer on S08 items drops below ~30 s |
| Difficulty starting | **Tomorrow's first move is written tonight.** Literally one sentence in the log. | Daily | Zero days lost to "I didn't know where to start" |
| Grammar decay | **Weekly structure maintenance drill** in Weeks 2–5. | Weekly (D20, D31, D36) | Retest of old misses ≥ 90% |

### B. Task adjustments

These change **how** the work is done, never **what** is being measured. The test itself cannot
be adjusted here — only the practice.

| Adjustment | What changes | What does NOT change |
|---|---|---|
| Split long tests into two sittings during practice (Weeks 0–3) | Practice only | From Mock #1 (Day 27) onward: **full 115 minutes, straight through.** No exceptions — this is the real demand. |
| Untimed exercises while learning a new module | Practice only | **Every drill from Week 2 onward is timed.** Untimed practice measures something the exam doesn't. |
| Flashcards instead of prose for vocabulary | Format only | You still have to recognise the word in a passage with no context help |
| Write the rule in your own words before drilling | Sequencing only | You still have to apply it at 37 s/question |
| Allow one rescheduled session per week | Scheduling only | The weekly checkpoint still happens; a missed drill is made up within 48 h |

> ⚠️ **Do not** practise with extended time and then expect the real timing to feel fine.
> Splitting practice is a *learning* adjustment for Weeks 0–3 only, and it is deliberately
> removed before the mocks.

## 5. Boundaries

- **This is not an assessment of ability.** A low diagnostic score describes a starting point,
  not a ceiling. Section 2 in particular is highly trainable in six weeks.
- **No diagnosis is made or implied.** Nothing here requires one. Study-access strategies are
  useful regardless of the reason a task is hard.
- **Accommodations:** if you think you need extra time, a separate room, or any other adjustment
  **on the test day**, apply to your administering institution through their formal process.
  Do it early — deadlines are set by them, not by this plan. Nothing in this repo substitutes
  for that.
- **Stop or change any strategy that causes distress or makes study impossible.** A plan you
  can't follow is worse than a smaller plan you can.
- **No forced public performance.** Nothing here asks you to post scores or compare yourself
  publicly.
