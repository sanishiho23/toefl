## D2
**Tue 6 Oct · S01 — Subject–verb agreement & word order** · 100 min

**Objective:** Find the *real* subject in a sentence full of decoys. This single skill fixes
more Section 2 questions than any other.

- **Material:** [S01   Subject Verb Agreement](<../study-notes/structure/[06-Oct] S01 - Subject-Verb Agreement.md>)
- **Drill:** S01 exercise set (20 items) + [Structure Test 01](<../hands-on/[17-Oct] Structure Test 01.md>) questions 1–15 only
- **Log:** `docs/logs/daily/week-00/06-10-2026.md`

| Block | Min | Task |
|---|---:|---|
| Warm-up | 5 | Reread yesterday's five error-log rows. |
| Instruction | 25 | Read S01. Copy the five decoy patterns onto a paper card. |
| Guided practice | 20 | S01 exercises — untimed, check after every 5. |
| Timed drill | 25 | Structure Test 01, Q1–15, **9 minutes**. |
| Error review | 20 | Every miss → error log with the decoy pattern named. |
| Commit | 5 | Fill the log, commit. |

**The five decoys to memorise today:**
1. prepositional phrase between subject and verb — *The **results** of the study **were***…
2. inverted sentence — *There **remain** several questions*…
3. `of the` / `one of the` — *one of the students **is***
4. gerund/participial phrase — *Running five miles **is***
5. collective & quantity nouns — *a number of **are*** vs *the number of **is***

**Success criteria:** ≥ 16/20 on S01 exercises, and you can name the decoy on every miss.

## D3
**Wed 7 Oct · S02 — Verb tenses & time markers** · 100 min

**Objective:** Stop guessing tense. The adverb in the sentence already told you.

- **Material:** [S02   Verb Tenses and Time Markers](<../study-notes/structure/[07-Oct] S02 - Verb Tenses and Time Markers.md>)
- **Drill:** S02 exercise set (20 items) + Structure Test 01 Q16–30
- **Log:** `docs/logs/daily/week-00/07-10-2026.md`

| Block | Min | Task |
|---|---:|---|
| Warm-up | 5 | S01 card: recite the five decoys from memory. |
| Instruction | 25 | Read S02. Build a two-column table: *marker → tense*. |
| Guided practice | 20 | S02 exercises, untimed. |
| Timed drill | 25 | Structure Test 01, Q16–30, **9 minutes**. |
| Error review | 20 | Error log. Tag each miss with its time marker. |
| Commit | 5 | |

**Markers that decide the answer:** `since` → present perfect · `by the time` → past perfect ·
`yesterday / in 1998 / last` → simple past · `now / currently` → present · `next / tomorrow` → future ·
`for two hours` → perfect · `when + past` → past · `always` → present.

**Success criteria:** ≥ 16/20, and every miss tagged with the marker you overlooked.
