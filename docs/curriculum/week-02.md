# Week 02 — Reading comprehension
**Mon 19 Oct → Sun 25 Oct 2026** · Days 15–21 · Theme: *50 questions in 55 minutes*

Back to [curriculum README](<README.md>) · [repo README](<../../README.md>)

> Reading is the only section where you can see the questions while you work. That makes it
> the most *trainable* section — but only if you stop reading like a novel. This week you
> learn to read like a search engine, and you build the vocabulary that S08 also depends on.

---

## D15
**Mon 19 Oct · R01 — The 8 question types** · 100 min

- **Material:** [R01   Question Types](<../study-notes/reading/[19-Oct] R01 - Question Types.md>)
- **Log:** `docs/logs/daily/week-02/19-10-2026.md`

| Block | Min | Task |
|---|---:|---|
| Warm-up | 5 | Structure maintenance: 10 random S01–S08 items. |
| Instruction | 30 | Read R01. Learn all 8 types and the order to attack them in. |
| Guided practice | 25 | Type-identification drill: label 20 questions, don't answer them. |
| Timed drill | 15 | One passage, 10 questions, **11 min**. |
| Error review | 20 | Error log, tagged by question type. |
| Commit | 5 | |

**The order that saves time:** vocabulary-in-context → detail (scan) → NOT/EXCEPT →
pronoun reference → inference → main idea → tone/purpose → insert-a-sentence.

**Success criteria:** You can label 18/20 questions correctly in under 60 seconds total.
