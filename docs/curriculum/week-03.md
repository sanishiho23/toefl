# Week 03 — Listening comprehension + first full mock
**Mon 26 Oct → Sun 1 Nov 2026** · Days 22–28 · Theme: *one pass, no replay*

Back to [curriculum README](<README.md>) · [repo README](<../../README.md>)

> The audio plays **once**. There is no rewind button in the room. Everything this week is
> about building the skill of *capturing meaning on a single pass* — notes, prediction, and
> letting go of the question you missed.

- **Material:** [L01   Part A Strategy](<../study-notes/listening/[10-Oct] L01 - Part A Strategy.md>)
- **Log:** `docs/logs/daily/week-03/26-10-2026.md`

| Instruction | 30 | Read L01. The 6 Part A types: function, inference, location/occupation, suggestion, contrast, sequence. |
| Audio | 30 | [ETS official Part A samples](https://toefl-samples.ets-rschtech-prod.c.ets.org/toefl_www/toefl_itp/test_preparation/sample_questions/level1_section1_listening_comprehension.html) — one pass. |
| Analysis | 20 | Tag each miss by type. |
| Error review | 10 | Error log. |
| Commit | 5 | |

**The rule that changes everything:** if the response does not literally answer the question,
it is a **function** question — ask *what is the speaker DOING?* (suggesting / refusing /
surprised / agreeing / hedging).

**Success criteria:** You can name the question type on ≥ 80% of items.
