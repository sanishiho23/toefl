# E06 — Travel and Hospitality

**Where it pays off:** Listening Part A (service conversations: hotels, airports, restaurants,
ticket counters are common ITP settings) and real-world travel. Pairs with
[E02 — Directions and Places](<E02 - Directions and Places.md>).
**Time to learn:** 20 min · **Target on the drill:** ≥ 12 / 15.

> Service English is **formulaic** — the same 30 phrases cover almost every situation.
> Learn them as fixed chunks so you recognise them instantly in the audio.

---

## 1. The spelling / phonetic alphabet

When you spell a name on the phone or at a counter, native speakers use "A as in Alpha."

| A Alpha · B Bravo · C Charlie · D Delta · E Echo · F Foxtrot · G Golf |
|---|
| H Hotel · I India · J Juliet · K Kilo · L Lima · M Mike · N November |
| O Oscar · P Papa · Q Quebec · R Romeo · S Sierra · T Tango · U Uniform |
| V Victor · W Whiskey · X X-ray · Y Yankee · Z Zulu |

*"My surname is Sani — S as in Sierra, A as in Alpha, N as in November, I as in India."*

## 2. Hotel check-in / check-out

| Function | Phrase |
|---|---|
| Arriving | *I have a reservation under the name…* |
| No booking | *Do you have any rooms available (for tonight)?* |
| Asking details | *Is breakfast included?* / *What time is check-out?* |
| Requests | *Could I have a wake-up call at seven?* / *Is there Wi-Fi in the room?* |
| Problems | *The air conditioning isn't working.* / *There's a problem with…* |
| Leaving | *I'd like to check out.* / *Could I have the bill, please?* |
| Staff reply | *Certainly.* / *Let me check for you.* / *You're all set.* |

## 3. At the airport

| Function | Phrase |
|---|---|
| Check-in | *I'd like to check in for the flight to Tokyo.* |
| Bags | *Just one bag to check / only carry-on.* |
| Reason for travel | *Business.* / *Tourism.* / *I'm visiting family.* |
| Boarding | *Which gate does it leave from?* / *Has the flight started boarding?* |
| Delays | *The flight has been delayed / cancelled.* |
| Useful nouns | boarding pass, gate, aisle/window seat, layover, baggage claim, customs |

## 4. Restaurants and ordering food

| Function | Phrase |
|---|---|
| Being seated | *A table for two, please.* |
| Ordering | *I'll have the…* / *Could I get the… ?* / *What do you recommend?* |
| Dietary | *Is this dish vegetarian?* / *I'm allergic to nuts.* |
| During | *Could we have the menu / some water, please?* |
| Paying | *Could we have the bill/check, please?* / *Can we pay separately?* |
| Server | *Are you ready to order?* / *How would you like it cooked?* / *Anything else?* |

## 5. Polite time-of-day greetings & register

| Situation | Say |
|---|---|
| Morning (before ~12) | *Good morning.* |
| Afternoon (~12–6) | *Good afternoon.* |
| Evening (after ~6) | *Good evening.* (greeting) — *Good night* is only for **leaving/bed** |
| Polite softeners | *Could you…?* / *Would it be possible to…?* / *I'm sorry to bother you, but…* |
| Thanking | *Thanks so much.* / *I really appreciate it.* |

**Register note:** service English is polite-neutral. Use *could/would*, not bare imperatives
(*"Give me a room"* sounds rude; *"Could I have a room?"* is correct).

## Exercise — 15 items, 8 minutes

**Choose the best phrase (1–10).**

1. At reception: "I have a reservation (under / below) the name Sani."
2. "What time is (check-out / check-off)?"
3. At the airport: "I'd like to (check in / check up) for the flight to Osaka."
4. The officer asks your reason for travel; you're a tourist: "(Tourism / Touristic)."
5. In a restaurant: "A table (for / of) two, please."
6. "Could we have the (bill / money), please?"
7. "I'm (allergic to / allergic with) nuts."
8. Leaving at 9 p.m. you say: "(Good evening / Good night)" — to say goodbye.
9. Polite request: "(Give me / Could I have) a wake-up call at six?"
10. Spelling "Sani": "S as (in / for) Sierra…"

**Fix / complete (11–15).**

11. Spell your first name using the phonetic alphabet (any name). →
12. Make a polite complaint about a broken air conditioner. →
13. Ask whether breakfast is included. →
14. Ask the server for a recommendation. →
15. Ask to pay separately. →
