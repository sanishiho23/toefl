# E05 — Gen Z Slang 🚫 *Off-test — general English enrichment only*

> ## ⚠️ Read this first
> **None of this is on the TOEFL ITP.** The ITP tests formal, academic, and *everyday
> conversational* English — not internet slang. Slang changes every year, it is informal
> register, and using it in the test's Written Expression section would be **marked wrong**.
>
> This page exists because you asked for it, and because understanding slang helps with
> real-world conversation, YouTube, and games. **Do not spend scheduled study time on it.**
> Read it on a rest day. The point is *recognition*, not *production* — and never in an exam.

**Where it pays off:** real-life casual conversation, social media, streaming — **not the test.**

## 1. Common Gen Z slang (recognition only)

| Slang | Meaning | Formal equivalent (use this on the test) |
|---|---|---|
| no cap | no lie, for real | *honestly, truly* |
| cap / capping | a lie / lying | *that's false* |
| bet | okay / agreed | *all right, agreed* |
| lowkey / highkey | slightly / very / secretly / openly | *somewhat / very* |
| vibe / vibes | mood, atmosphere | *atmosphere, feeling* |
| slay | do something excellently | *do very well* |
| mid | mediocre, not great | *average, unremarkable* |
| sus | suspicious | *suspicious, dubious* |
| rizz | charm, charisma | *charisma* |
| ghosting | cutting off contact suddenly | *cutting off contact* |
| flex | to show off | *to show off, to boast* |
| salty | bitter, resentful | *resentful, annoyed* |
| GOAT | greatest of all time | *the best ever* |
| it's giving… | it resembles / has the energy of | *it seems like, it resembles* |
| based | admirably true to oneself | *(no direct formal equivalent)* |
| touch grass | go outside / get real | *take a break from the internet* |

## 3. Register — the one thing that matters for your goal

Everything in English sits on a **register** scale. The test wants the right end:

```
slang / internet  →  casual spoken  →  neutral  →  formal / academic (← ITP lives here)
"no cap, it's mid"    "it's not great"   "it is mediocre"   "the result was unremarkable"
```

**The transferable skill:** for every slang term, know its **neutral/formal** twin (the
right-hand column in §1). That is the version that scores points in Structure, Reading,
and any real writing. Slang in = wrong answer out.
