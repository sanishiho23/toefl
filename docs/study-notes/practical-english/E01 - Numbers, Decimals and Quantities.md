# E01 — Numbers, Decimals and Quantities ⭐

**Where it pays off:** Listening Comprehension (Part A short conversations + Parts B/C talks).
Spoken numbers — prices, dates, years, statistics, measurements — are a classic trap: the
audio plays **once**, and the answer choices are near-miss numbers (*1,850 / 1,580 / 15,800*).
**Time to learn:** 25 min · **Target on the drill:** ≥ 16 / 20.

> This is not "math." It is **hearing** a number correctly the first time and writing it fast.
> Train your ear, not your arithmetic.

---

## 1. Reading big numbers aloud

English groups digits in **threes**, and each group has a name: *thousand, million, billion*.

| Number | Said as |
|---|---|
| 1,500 | *one thousand five hundred* — or informally *fifteen hundred* |
| 12,000 | *twelve thousand* |
| 250,000 | *two hundred (and) fifty thousand* |
| 1,000,000 | *one million* |
| 3,400,000 | *three point four million* / *three million four hundred thousand* |
| 2,000,000,000 | *two billion* |

Rules that trip up Indonesian speakers:
- English has **no word for "ten thousand"** as one unit — *10,000* is *ten thousand*, not one unit like *puluh ribu*. Count in thousands/millions only.
- *hundred, thousand, million* stay **singular** after a number: *three hundred* ✓, ~~three hundreds~~ ✗.
- British/formal English adds *and*: *one hundred **and** five* (105). American often drops it.
- A comma `,` marks thousands; a point `.` marks the decimal. (Opposite of Indonesian.)

## 2. Decimals, fractions, percentages

| Written | Said as |
|---|---|
| 0.5 | *(zero) point five* / *nought point five* |
| 3.14 | *three point one four* (digits one by one after the point) |
| 0.075 | *point zero seven five* |
| 1/2 | *a half* / *one half* |
| 1/3 | *a third* / *one third* |
| 2/3 | *two thirds* (plural!) |
| 3/4 | *three quarters* |
| 7% | *seven percent* |
| 0.5% | *half a percent* / *(zero) point five percent* |

**Key ear-trap:** after the decimal point you say **each digit separately** —
*3.14 = "three point one four,"* never *"three point fourteen."*

## 3. Dates and years

| Written | Said as |
|---|---|
| 1985 | *nineteen eighty-five* |
| 1900 | *nineteen hundred* |
| 2007 | *two thousand (and) seven* / *twenty oh seven* |
| 2019 | *twenty nineteen* / *two thousand nineteen* |
| July 4 | *July (the) fourth* / *the fourth of July* |
| 3/7 (US) | *March seventh* — **US = month/day** |
| 3/7 (UK) | *the third of July* — **UK = day/month** |
| the 1990s | *the nineteen nineties* |

Dates always use **ordinals** when spoken: *the first, the second, the third, the twenty-third*.

## 4. Prices, phone numbers, measurements

| Context | Example written | Said as |
|---|---|---|
| Price | $19.99 | *nineteen (dollars) ninety-nine* / *nineteen ninety-nine* |
| Price | $1,250 | *twelve fifty* (informal) / *one thousand two hundred fifty* |
| Phone | 555-0147 | *five five five, oh one four seven* (digit by digit; *0 = "oh"*) |
| Room/flight | Room 305 | *room three oh five* |
| Temperature | 25°C | *twenty-five degrees (Celsius)* |
| Weight | 2.5 kg | *two point five kilos* / *two and a half kilos* |
| Time | 7:45 | *seven forty-five* / *(a) quarter to eight* |
| Time | 8:15 | *eight fifteen* / *(a) quarter past eight* |

## 5. The sound traps — -teen vs -ty

The single most tested number confusion in Listening:

| -teen (stress on the END) | -ty (stress on the FRONT) |
|---|---|
| thir**TEEN** (13) | **THIR**ty (30) |
| four**TEEN** (14) | **FOR**ty (40) |
| fif**TEEN** (15) | **FIF**ty (50) |
| nine**TEEN** (19) | **NINE**ty (90) |

Listen for the **stress** and the final *-n* of *-teen*. When the whole word is stressed
and ends in a clear *n*, it is *-teen*. When the first syllable is stressed, it is *-ty*.

## Exercise — 20 items, 10 minutes

**A. Write the number you would hear (1–10).** Read each "said as" and write the digits.

1. *one hundred and twenty thousand* → ______
2. *three point five million* → ______
3. *point zero six* → ______
4. *two thirds* → ______
5. *nineteen ninety-eight* (year) → ______
6. *twenty oh five* (year) → ______
7. *a quarter to nine* → ______ : ______
8. *fourteen* vs *forty* — which ends with a stressed *-n*? → ______
9. *twelve fifty* (price, informal) → $______
10. *the fourth of July* → month ______ day ______

**B. Spot the error (11–20).** Each "said as" is wrong — fix it.

11. 2,000,000 → *"two millions"*
12. 3.14 → *"three point fourteen"*
13. 105 → *"one hundred five and"*
14. 0 in a phone number → *"zero zero"* (how is it usually said?)
15. 3/4 → *"three quarter"*
16. 1985 → *"one thousand nine hundred eighty-five"* (what's the natural spoken form?)
17. 50% → *"fifty percents"*
18. July 4 → *"July four"*
19. $19.99 → *"nineteen point ninety-nine"*
20. 2/3 → *"two third"*
