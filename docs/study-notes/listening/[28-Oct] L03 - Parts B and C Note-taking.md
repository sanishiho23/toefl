# L03 — Parts B & C: Longer Conversations and Lectures

**Section:** Listening Comprehension · **Est. yield:** 20 of the 50 listening questions
**Time to learn:** 30 min

- **Part B:** ~2 longer conversations, 3–4 questions each (campus life: professor's office,
  registrar, housing, library)
- **Part C:** ~3 talks/lectures, 3–5 questions each (academic mini-lectures: biology, geology,
  history, art, astronomy)

The audio plays **once**. You cannot hold it in your head — you must put it on paper.

---

## The column layout

Fold your paper into two columns. Left = content, right = attitude/numbers.

```
TOPIC: _______________________
 1. ____________               • 1998 / 40% / 3 stages
 2. ____________               • however → BUT
 3. ____________               • example: ___
 4. ____________               • speaker: skeptical / impressed
```

**Rules:**
- Write **nouns and numbers**, not sentences.
- Use arrows and symbols: `↑` increase, `↓` decrease, `→` causes, `≠` differs, `?` uncertain.
- Abbreviate freely: *govt, dept, prof, info, exp, ~, w/, b/c*.
- Leave a blank line when you miss something — don't stop to chase it.

---

## Structure words = the map

These words tell you a new section is starting, which is exactly where questions come from:

| Function | Listen for |
|---|---|
| Listing | *first / second / finally / there are three types / another* |
| Contrast | *however / but / on the other hand / in contrast / whereas* |
| Cause–effect | *because / as a result / therefore / consequently / led to* |
| Example | *for example / for instance / such as / to illustrate* |
| Emphasis | *the most important / in fact / actually / above all / remember that* |
| Digression | *by the way / incidentally* |
| Definition | *which means / in other words / that is / refers to* |
| Conclusion | *in conclusion / to sum up / overall* |

> **A question follows almost every structure word.** If you hear "There are three reasons…",
> write 1 / 2 / 3 and get one question for free.

---

## Where the questions actually come from

| Question type | ~Share | How to prepare |
|---|---|---|
| Main topic / purpose | 20% | Note the first two sentences — the topic is announced there |
| Supporting detail | 30% | Numbers, dates, names, examples → the right column |
| Inference / implication | 20% | Tone words: *probably, seems, suggests, apparently* |
| Speaker attitude | 15% | Adjectives and intonation: *fascinating, disappointing, questionable* |
| Organisation / structure | 10% | Your 1 / 2 / 3 notes |
| Repetition / next step | 5% | The final sentence |

---

## Part B specifics — campus conversations

1. **Identify the problem in the first 15 seconds.** Every Part B dialogue is: *problem →
   options → decision.*
2. **Note who suggests what.** Suggestions are tested constantly.
3. **The ending matters.** The resolution is usually the last question.

## Part C specifics — lectures

1. **Get the topic from sentence one.** It's almost always stated: *"Today we'll look at…"*
2. **Don't panic at technical vocabulary.** It's usually spelled out or exemplified.
3. **Watch for the professor's opinion.** *surprising / controversial / widely accepted /
   recently challenged* — these signal an attitude question.

## The 20-minute daily drill

| Min | Task |
|---:|---|
| 3 | Pick one script from [L04](<[24-Oct] L04 - Audio Script Bank.md>). Don't read it. |
| 3 | Play it once (TTS or a reader). Take notes. No pausing. |
| 5 | Answer the questions from notes only. |
| 5 | Read the script. Mark where each answer was hidden. |
| 4 | Rewrite your notes the way you *should* have taken them. |

---

## Non-negotiables

- **Never look back.** A missed item is gone. Bubble a guess and re-engage.
- **Notes are for the test, not for your archive.** Messy is fine.
- **Numbers get their own box.** Dates, percentages, quantities = free questions.
