Print this. Read it the night before and the morning of the exam.

## Section 2 — Structure & Written Expression

### Clause connectors — who / whom / whose / which / that

| See this | Pick this | Why |
|---|---|---|
| **he** fits the blank | **who** | subject |
| **him** fits the blank | **whom** | object |
| **his** fits the blank | **whose** | possession |
| commas around the clause | **which** (things) or **who** (people) | non-restrictive — never *that* |
| no commas | **that** or **who** | restrictive |
| preposition + ___ | **which** (things) or **whom** (people) | never *in that* or *to who* |
| *the reason … is ___* | **that** | never *is because* |

### -ed vs -ing adjectives

| The ___ causes the feeling | → **-ing** | *The movie is boring.* |
|---|---|---|
| The ___ feels the emotion | → **-ed** | *I am bored.* |

### Gerund vs infinitive vs base verb

| Pattern | Rule | Examples |
|---|---|---|
| avoid, enjoy, mind, deny, suggest, finish, consider + ___ | **gerund** (-ing) | *avoid answering* |
| decide, expect, hope, agree, plan, arrange, refuse + ___ | **infinitive** (to + base) | *decided to leave* |
| make, let, have (active) + object + ___ | **base verb** (no *to*) | *made him revise* |
| have + object + ___ (passive) | **past participle** | *had the script rewritten* |
| ask, tell, advise, order + object + ___ | **to + base** | *told her to wait* |
| look forward to / be used to / object to + ___ | **gerund** (*to* = preposition) | *look forward to meeting* |
| too + adj + ___ | **to + base** | *too complicated to follow* |
| remember + ___ (past event) | **gerund** | *remember meeting her* |
| remember + ___ (future task) | **infinitive** | *remember to lock the door* |

### Subjunctive

After **recommend, suggest, insist, demand, require, essential, important, necessary** + that:

→ Always **base verb** or **be** (no *-s*, no *will*, no *was*).

*He insisted that she **attend**.* · *It is essential that the report **be** submitted.*

### Reported speech — shift one tense back

| Direct | Reported |
|---|---|
| *"I **will** come."* | He said he **would** come. |
| *"I **have** finished."* | She said she **had** finished. |
| *"I **can** help."* | He said he **could** help. |
| *"I **am** working."* | She said she **was** working. |

### Whether vs if

| Position | Use |
|---|---|
| **Subject** clause | **whether** only | *Whether he agrees is unclear.* |
| After **preposition** | **whether** only | *It depends on whether…* |
| After *not sure / ask / wonder* | both OK, **whether** is safer |

### Despite vs although vs because

| Word | Follows with | Example |
|---|---|---|
| **despite / in spite of** | noun phrase | *Despite the rain, …* |
| **although / even though** | full clause | *Although it rained, …* |
| **because** | full clause | *Because it rained, …* |
| **because of / due to** | noun phrase | *Because of the rain, …* |

### So vs such

| Pattern | Example |
|---|---|
| **so** + adjective / adverb + that | *so difficult that…* |
| **such** + (a/an) + noun phrase + that | *such a difficult test that…* |

### Conditionals

| Type | If-clause | Main clause |
|---|---|---|
| 1st (real future) | present simple | will + base |
| 2nd (unreal now) | past simple / **were** | would + base |
| 3rd (unreal past) | **had** + past participle | would have + pp |
| 3rd inverted | **Had** + subject + pp | would have + pp |

*Had I known = If I had known*

### Time clauses — no *will*

After **when, before, after, until, as soon as, by the time** → use **present simple** (not *will*).

*I'll call you **when** he **arrives**.* ✅ (not *when he will arrive*)

### Lying vs laying

| Word | Meaning | Object? |
|---|---|---|
| **lying** | resting, being in a position | no object |
| **laying** | placing something down | needs an object |

*The cat is **lying** on the bed.* · *She is **laying** the books on the table.*

### Subject–verb agreement traps

| Trap | Rule |
|---|---|
| prep phrase between subject and verb | ignore it — match the **headword** |
| *a number of* + plural noun | → **plural** verb |
| *the number of* + plural noun | → **singular** verb |
| *neither A **nor** B* | → verb agrees with **B** (nearest) |
| *one of those who…* | → **who** is plural |

## Section 3 — Reading Comprehension

### Question-type shortcuts

| Type | How to spot it | Strategy |
|---|---|---|
| **Main idea** | *"What is the passage mainly about?"* | Read first + last sentence of each paragraph. Eliminate too-narrow and too-broad options. |
| **Detail** | *"According to the passage…"* | Find the **paragraph number** first. The answer is a paraphrase, not a copy. |
| **NOT / EXCEPT** | *"All of the following EXCEPT…"* | Check each option against the text. Three are true — find the liar. |
| **Vocabulary** | *"The word X in line Y is closest in meaning to…"* | Re-read the **sentence** around the word. Meaning comes from context, not your memory. |
| **Inference** | *"It can be inferred…"* | The answer is one step from the text — never a wild guess. Look for "must be true." |
| **Reference** | *"The word 'they' in line Y refers to…"* | Go back to the sentence. The referent is almost always **before** the pronoun, usually in the same or previous sentence. |
| **Tone / purpose** | *"The author's attitude is…"* | Academic passages are almost always **neutral/objective**. Eliminate emotional extremes. |

### Reading speed rules

1. **Skim first** (2 min per passage): read first sentence of every paragraph → build a mental map.
2. **Go to the questions**, then hunt. Don't re-read the whole passage for each question.
3. **Paragraph questions go in order.** Q1 is usually about paragraph 1, Q2 about paragraph 2, etc.
4. **Never spend > 1.5 min on one question.** Mark it and come back.
5. **Eliminate two wrong answers** and pick from the remaining two — your odds go from 25% to 50%.

## Section 1 — Listening Comprehension

### Part A (short conversations) — 30 items

| Trick | What to listen for | Example |
|---|---|---|
| **Idiom / function** | The second speaker's reply = the answer | *"You can say that again!"* = I agree |
| **Hidden negative** | Double negatives, *barely, hardly, rarely* | *"I couldn't agree more"* = I totally agree |
| **Suggestion** | *Why don't we… / How about… / Let's…* | The answer restates the suggestion |
| **Implication** | The answer is what is **implied**, not what is literally said | *"Do I look like I enjoyed it?"* = No |

**Rule:** The **first answer that sounds exactly like the audio** is usually the trap. The correct answer **paraphrases**.

### Part B (longer conversations) — ~8 items

1. **First question** = topic or reason for the conversation.
2. **Listen for the relationship** (student-professor, doctor-patient, etc.).
3. **Numbers and names** are tested — jot them down.

### Part C (talks/lectures) — ~12 items

1. **First question** = main topic.
2. **Listen for signal words**: *however, in contrast, for example, the main point is…*
3. **Last question** often = what happens next or what the speaker implies.

### General listening rules

- **Don't get stuck.** If you miss one, let it go — the next question is already playing.
- **Read the answer choices** during the pause before each item.
- **The answer to a detail question** is usually said once, in passing — that's why they test it.
- **Guess before time runs out.** No penalty for wrong answers on the ITP.

## Exam-day quick checks

| Before you answer | Ask yourself |
|---|---|
| Structure: is there a **comma**? | → which/who, not that |
| Structure: is there a **preposition** before the blank? | → which/whom/whether |
| Structure: is the sentence **reported speech**? | → shift tense back |
| Structure: is there **recommend/insist/essential**? | → base verb or be |
| Reading: does the question say **"in line X"**? | → go to that line first |
| Reading: does it say **NOT/EXCEPT**? | → three are true, find the false one |
| Listening: does the answer **copy the audio word-for-word**? | → probably a trap |
