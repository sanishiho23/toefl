# Study Setup Guide

Everything you need before day 1. Ten minutes of setup saves an hour a week.

---

## 1. The repository

```bash
git clone https://github.com/sanishiho23/toefl.git
cd toefl
```

Regenerate the daily logs at any time (never overwrites filled entries unless `--force`):

```bash
python tools/generate_daily_logs.py
```

## 2. Timer

You need one timer that is **visible while you work** and does not live on your phone.

- Recommended: a kitchen timer, or a browser tab with an online stopwatch.
- The phone is banned from the desk. It is the single largest source of lost minutes.

## 3. Audio for Listening

TOEFL ITP audio plays **once**. You must be able to play a script once, with no possibility
of replaying it.

| Option | Setup |
|---|---|
| **Best** | [ETS official Level 1 listening samples](https://toefl-samples.ets-rschtech-prod.c.ets.org/toefl_www/toefl_itp/test_preparation/sample_questions/level1_section1_listening_comprehension.html) |
| **Script bank** | Paste a script from [L04 — Audio Script Bank](<./study-notes/listening/[24-Oct] L04 - Audio Script Bank.md>) into any TTS app and play at ~150 wpm |
| **Windows** | Settings → Accessibility → Narrator, or PowerShell `Add-Type -AssemblyName System.Speech` |
| **Human reader** | Ask someone to read the script aloud once. Do not let them repeat. |

⚠️ Do **not** practise with podcasts or music. They train a skill the test does not measure.

## 4. Flashcards

Paper is fine and often better — writing engages more than tapping. You need three decks:

| Deck | Contents | Built on |
|---|---|---|
| Grammar | the S01–S08 rules that you actually miss | as you go |
| Word families | `decide / decision / decisive / decisively` | [Word Families](<./study-notes/vocabulary/[16-Oct] Word Families.md>) |
| Idioms | 120 expressions, plain-English gloss | [Idiom Bank](<./study-notes/listening/[27-Oct] L02 - Idiom Bank.md>) |

Spaced repetition schedule: every card is seen on day 0, 1, 2, 7, 21. That is enough for
recognition-level knowledge, which is all the test requires.

test honestly later.

## 6. The exam-day bag

Lay this out on **11 November**, not on the morning of:

- [ ] ID / passport
- [ ] Admission ticket
- [ ] 2–3 sharpened HB pencils + eraser
- [ ] Analogue watch (smartwatches are usually banned)
- [ ] Water
- [ ] Light snack
- [ ] The top-5 patterns card from the [error log](<../progress/error-log.md>)

## 7. Verify before exam week

Two things only your institution can tell you:

1. **Paper or digital?** (Affects whether you can write on the test book.)
2. **Level 1 or Level 2?** (They are not interchangeable.)

Write the answers in [Important Dates](<./logs/Important Dates.md>).
